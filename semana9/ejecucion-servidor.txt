Al ejecutar node server.js, Node.js inicia el proceso del servidor y
en la terminal aparece el mensaje:
"Servidor ejecutándose en puerto 3000"

Esto indica que el servidor está activo y esperando solicitudes.

Al visitar http://localhost:3000 en el navegador, el servidor responde
con el texto: "Servidor activo y funcionando"

Al visitar http://localhost:3000/estado, el servidor devuelve un JSON:

{
  "estado": "Servidor funcionando",
  "servicio": "API comunitaria"
}

El servidor sigue funcionando hasta que se detiene manualmente con
Ctrl + C en la terminal.
