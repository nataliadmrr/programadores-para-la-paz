Al enviar una petición POST a http://localhost:3000/registro con el
siguiente JSON:

{
  "nombre": "Maria",
  "mensaje": "Hola comunidad"
}

El servidor responde con:

{
  "estado": "Datos recibidos",
  "nombre": "Maria",
  "mensaje": "Hola comunidad"
}

Esto ocurre porque Express lee los datos enviados en el cuerpo de la
petición mediante req.body, los extrae y los devuelve en formato JSON
confirmando que fueron recibidos correctamente.
